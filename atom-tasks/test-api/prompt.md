# test-api

> 接口测试执行阶段：检查接口测试计划 → 执行计划 → 产出测试报告。接口层保证 req、resp 符合预期并能调通。

<!-- @phase:01 -->
## 执行接口测试计划

1. 读取 Context 中的接口测试计划（test-design.md 的「接口测试计划」section）。缺失（未启用 api 或计划无该节）→ 停止并报告位置错误，不得自行编造计划。
2. 确认执行前置：按计划所需的服务/环境启动方式就绪（需要启动服务时先启动并在报告记录启动方式）；请求工具优先项目既有接口测试设施，无既有设施时经宿主提问工具与用户确认（curl/httpie/项目脚本）。
3. 逐项执行计划接口：发出请求、断言 resp（状态码/关键字段）、确认调通。
4. 写入 run 目录 `api-test-report.md`：`## 执行说明`（工具与前置，如服务启动方式）、`## 接口结果`（表格逐项：接口/请求摘要/resp 断言/调通）、`## 结论与失败项`。
