# context

> 读取项目基础上下文（AGENTS.md + 项目基线文档）并汇总为 context-summary 产物。缺失项不阻断，但要如实记录。

## 指令

1. 读取本次目标项目根目录的 AGENTS.md（若存在）；项目基线上下文路径（contextPaths）从 run 状态或用户配置获取——它们**相对 projectRoot 解析**，不相对 worktree 目标目录；
2. 对每个声明的输入：存在则读取并生成一行摘要；不存在则记入「上下文缺失」列表；
3. 输入为目录时递归遍历 depth-3，仅收 `.md` / `.txt` 文件；
4. 生成 `context-summary.md`，包含两个 section：
   - **已加载来源**：文件路径 + 一行摘要（每来源摘要 ≤ 8 行，不大段复制内容）；
   - **上下文缺失**：声明了但实际不存在的文件列表。

## 约束

- contextPaths 是跨需求稳定的项目级基线上下文（架构文档、编码规范等）；按需求变化的上下文走 issue-context 或运行参数，不混入本产物。
