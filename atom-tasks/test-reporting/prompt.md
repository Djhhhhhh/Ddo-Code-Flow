# test-reporting

> 测试工作流收尾：聚合测试范围、分层计划与各执行层报告，产出测试总结。只汇总既有产物，不重新执行测试。

<!-- @phase:01 -->
## 生成测试总结

1. 读取 Context 注入的上游产物：test-scope.md、test-design.md（必需）与已存在的各层报告（unit-test-report.md / api-test-report.md / e2e-test-report.md——按启用裁剪可能缺失，缺失=该层未启用）。
2. 写入 run 目录 `test-reporting.md`：
   - `## 测试总览`：范围回顾（来源与范围条目概览）、启用能力、各层执行形态摘要；
   - `## 各层结果汇总`：表格逐层（层级/用例数/通过/失败/遗留）——未启用层标注「未启用」；全部层未启用时如实呈现「仅计划、无执行」形态；
   - `## 遗留项与建议`：失败项、人工执行待办（人工指南形态）、依赖缺失记录，逐条注明来源报告。
