# test-unit

> 单元测试执行阶段：检查单元测试计划 → 执行计划 → 产出测试报告。单测保证代码基础能力，不越层。

<!-- @phase:01 -->
## 执行单元测试计划

1. 读取 Context 中的单元测试计划（test-design.md 的「单元测试计划」section）。缺失（未启用 unit 或计划无该节）→ 停止并报告位置错误，不得自行编造计划。
2. 检测项目测试框架与测试目录约定；无既有框架时经宿主提问工具与用户确认落地方式后再执行。
3. 按计划用例落地并执行：
   - **测试性能优先（串行）**：每次执行 1-3 条——分批运行、逐批记录结果后再进入下一批；
   - **效率优先（并行）**：全部用例一次性执行后汇总记录。
4. 写入 run 目录 `unit-test-report.md`：`## 执行模式`（实际使用的模式及来源：计划/用户改选）、`## 用例结果`（表格逐条：用例/结果/证据）、`## 结论与失败项`。
