# git-worktree

> 基于 Requirement 提取关键词，创建 Git 分支与隔离工作树，供本次 run 的全部代码改动在其中进行。

## 执行步骤

1. **生成分支名**：从 Context: Requirement 提取描述性关键词（跳过激活词如「use ddo-code-flow」），转 kebab-case（小写、去特殊字符、空格转连字符），截断到 50 字符。提取失败时向用户索取一句描述后再提取。按 run 类型决定前缀：feature → `feat/`、bugfix → `fix/`，其余沿用有效配置的默认类型。
2. **计算目录**：项目名 = 项目根目录 basename；工作树目录名 = `<项目名>-<分支名（/ 替换为 -）>`；工作树路径 = worktreeDir（缺省为项目根的父目录）拼接该目录名。
3. **创建**：从基线分支 `git branch <分支名>`（已存在则追加 `-2`、`-3` 直至唯一）→ `git worktree add <工作树路径> <分支名>` → 验证 exit code 为 0 且目录存在；任何 git 失败（非 git 仓库、脏工作区等）立即暂停并报告，不得继续。
4. **切换工作目录**：使用 agent 自带的 worktree 切换工具（如 Claude Code 的 EnterWorktree，path 指向新工作树）切换会话工作目录；**不得**用 `cd` 代替。切换后用 `pwd` 验证。

## 约束

- 不得修改主工作树中的任何文件；仅在新工作树上操作。
- 分支与工作树的命名信息写入 run 状态由流水线负责，本任务只做 Git 层动作。
- 工作树路径必须是绝对路径。
