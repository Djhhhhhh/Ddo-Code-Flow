# delivery-doc

> 生成交付文档：需求回溯、变更清单、风险说明、验证结论。用于 PR 正文与 issue 评论。

## 指令

读取 Context 中的 Alignment Spec 与 Plan（必需），Test Plan 与验证日志（如有），生成 `delivery-doc.md`：

1. **项目概述**：spec 的目标一段话回溯；
2. **需求回溯**：原始需求引用（不改写）→ FR 清单 → 交付对照；
3. **变更清单**：按 Plan 的文件变更计划与实际改动汇总（文件 + 职责一句话）；
4. **风险说明**：Plan 中的回退条件、未消化的假设、Non-goals 提示；
5. **验证结论**：如实转述验证日志的通过/失败状态，不得夸大。
