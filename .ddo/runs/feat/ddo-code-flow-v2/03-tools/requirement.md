## 收敛理由（D7）

- 后续需求（原子任务联动、workflow 预设、执行循环）可能带来逻辑变更——当前阶段实现命令接口与机制是预付 churn 成本。
- 未定型的接口（flag 语义、推进语义、临时占位参数）会在归属设计轮被重塑，提前实现还会诱导调用方依赖临时形态。
- 机制规格已在 02 基线（v1.0）精确固化，归属轮重实现成本低。

## 命令登记原则

- 命令在**归属的设计轮次**登记进注册表；不预留占位接口、不做前瞻实现。
- 下一轮预期登记方向（以届时设计为准）：`next`（原子任务推导）、产物登记、Prompt 组装、workflow 预设展开，以及随执行循环设计定型的 run 生命周期命令。
