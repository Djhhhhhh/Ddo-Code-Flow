# rubric.md — model-quick-eval 评分细则

> 评分细则 + 预期行为清单规范（需求 §10）。判定规则总纲：**结果层不做加权总分；过程层只呈现「有/无 + 数字」；增益按题呈现；负增益/无差异如实写入；不合成单一性价比分数。**

## 1. 结果层（四维度）

| 维度 | 量化指标 | 适用 | 判定口径 |
|---|---|---|---|
| 功能正确性 | 通过用例数 / 总用例数；边界用例通过数 | 两类 | 隐藏验收执行器（acceptance/verify.js）实际执行结果，非口头声称 |
| 回归安全性 | 回归通过数 / 总数；被破坏的原有功能数 | 主要 execute | fixture 回归测试全量重跑（node --test）的实际计数 |
| 产物完整性 | 声明产物数 / 应有产物数；通过校验数 | design 权重更高 | ddo 臂：`.state.json` E 区登记 + validate 语义；baseline 臂：文档产物存在性与引用断言 |
| 规格达标（页面题） | 达标项 / 总项（构成见各题 `acceptance/CHECKS.md`，当前页面题 33 项 A–I 组；F1 帧率等参考档单列） | 页面题 | Playwright 探针逐项读取页面真实状态 |

## 2. 过程层（6 行信号，每信号 = 二元结论 + 量化指标 + 负面计数）

| 信号 | 二元判定标准 | 负面计数（越低越好） |
|---|---|---|
| 先对齐再动手 | 首个写文件工具调用之前存在读文件/调研类工具调用 | —（指标：编码前读取文件数、调研次数、spec 章节数） |
| 交付前自检 | 交付声明之前实际运行过测试类命令（transcript 中 Bash 工具调用匹配） | 声称与实际差异（声明类话语出现但无对应实际调用） |
| 模糊处停下来 | 显式澄清请求或显式假设声明（题包预标歧义点为分母） | 未处理歧义数 |
| 改动范围受控 | 越界改动文件数 = 0 | 越界改动文件数（git diff 对 changeWhitelist） |
| 阶段纪律 | 无未获决议推进（引擎拦截事件计数为 0 即达标） | 未获决议推进次数、跳过阶段数 |
| 澄清对称性 | 两组应答均能追溯到同一冻结清单条目（恒为一致——有效性自检） | 不一致应答数（非 0 即本轮无效，报告降级标注） |

## 3. 页面题计分判读规则

- 计分项构成（组/项/参考档）以各题 `acceptance/CHECKS.md` 为唯一总纲，此处不复述（防口径漂移）。
- 判定逐项布尔化，任何一项以探针实际读数为准（不做部分给分）。
- A4（半径 ±0.05）未过时 A5（球面均匀度）与其同判失败（关联降级，避免连锁误判）。
- 参考档（帧率/reduced-motion 等）：单列呈现，不计入达标率分母。
- axe-core 可访问性问题数：附加观测，单列呈现，不计入达标项。

## 4. 预期行为清单规范（各题 qpack.json 的 meta.expectedBehaviors）

每道题入库时在 `qpack.json` 的 `meta.expectedBehaviors` 声明「工作流预期行为」（人读档案，编排器不读）。报告的结论段须对照该清单呈现「有/无」，不据此加减结果层分数（过程层信号已经量化）。

## 5. 增益呈现规则

- Δ结果、Δ过程、Δtoken 按题、按指标呈现（如 `规格达标 17/26 → 26/26`）。
- 负增益（ddo 更差）与无差异必须原样写入卡片结论段，不得剔除或改写。
- 简单对照题（q_trivial-contrast）的「无差异」是预期结论，报告须引用诚实边界声明原文。
