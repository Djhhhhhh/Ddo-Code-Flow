# acceptance（隐藏验收）

页面题隐藏验收 = 探针清单 A1–I3（v2，见 acceptance/probe.js）。
本目录不随题面下发；探针在评测收集阶段对两臂产物执行。

计分项（33 项，达标率分母）：
- A 组 结构（A1–A11）：可观测性、几何、分布、连接线、双轨道环、颜色分组、线框叠加
- B 组 光照（B1–B4）：三类光源、阴影、底部冷色补光
- C 组 相机（C1–C3）：阻尼、缩放范围、响应式
- D 组 动画（D1–D4）：自转、卫星自转、中心浮动、失败卫星闪烁
- E 组 画面（E1–E2）：标题图例文本、画面有效性
- G 组 质感（G1–G2）：星空点数、bloom 后处理
- H 组 交互（H1–H4）：悬停放大+tooltip、点击聚焦+详情卡、图例过滤、空格暂停
- I 组 HUD（I1–I3）：FPS 计数、pixelRatio 上限、毛玻璃卡片

参考档（不计分母）：F1 帧率 ≥ 45；F2 prefers-reduced-motion 自转停用；axe 可访问性观测。
