# task-02 防交叉布局算法

## 目标

实现 Plan「算法设计」（PD-1）的布局计算：阶段主链水平排布、相位子节点垂直泳道、跨列边正交通道路由、两两线段自检计数。对应 spec FR-4 / AC-3。

## 涉及文件

- `visualize.js`（新增，布局计算部分）

## 执行步骤

1. 阶段主链按工作流顺序等距水平排布，主链相邻边为直线段；
2. 每阶段相位/门子节点放入该列下方垂直泳道，列间留隔离带；
3. 跨列边统一走顶部专属通道行：每条边分配互不重叠的通道行号（垂直上引 → 水平直行 → 垂直下引），通道行不足时按边数动态扩行；
4. 自检：全部边两两线段相交判定（不含共享端点），输出交叉计数；非 0 时调整通道行重排，≤3 轮；仍非 0 则如实报告计数（诚实边界）。

## 完成标准

- 本沙箱数据下自检交叉计数为 0；
- stdout 输出含 `crossings: <n>` 供 G3 验收。
